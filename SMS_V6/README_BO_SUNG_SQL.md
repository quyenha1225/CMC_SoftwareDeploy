# SQL và dữ liệu thực hành

Schema 01 và truy vấn 03 được giữ để đối chiếu. Seed 02 đã được sửa trực tiếp tên/mã theo yêu cầu mới của bạn. Đây là bộ dữ liệu hư cấu dùng vận hành thử; không phải hồ sơ chính thức của nhà trường.

Xem [bộ dữ liệu thực hành và bảng tên](../docs/BO_DU_LIEU_THUC_HANH.md), [SQL nâng cấp/cài mới](../data/v6/README.md). Cài đủ migration 05–12; không chạy lại schema gốc lên database đang có dữ liệu.
